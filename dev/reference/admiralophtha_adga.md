# Geographic Atrophy Analysis Dataset

An example Geographic Atrophy analysis dataset

## Usage

``` r
admiralophtha_adga
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with
11508 rows and 103 columns.

## Source

Derived from the OE and ADSL datasets using `{admiral}`,
`{admiralophtha}` and the [ADGA
template](https://github.com/pharmaverse/admiralophtha/blob/main/inst/templates/ad_adga.R).
